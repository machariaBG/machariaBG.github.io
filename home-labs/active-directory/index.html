Independent Home Lab

Active Directory Access Control & Identity Lifecycle

Lab Status: Completed Documentation: Published

Note: This is an independent home lab investigation and not a professional SOC or client incident-response experience.

Objective and Scope

To practice and validate identity and access-management workflows, including permissions and offboarding processes, in a controlled, non-production environment.

Lab Environment

  • Windows Server 2022 (Domain Controller)
  • Windows 11 (Client Endpoint)

What I Personally Did

  • Built and isolated the lab environment using Windows Server 2022 and Windows 11.
  • Configured group-based NTFS and SMB permissions for simulated departmental shares.
  • Tested permitted and denied access using standard, non-elevated user accounts.
  • Simulated password resets and complete account offboarding.
  • Documented account-disable and authentication tests.
  • Published a lab journal and evidence index to the repository.

Observations and Supporting Evidence

During the account offboarding simulations, I observed that while disabling an account prevents subsequent authentication attempts, it does not necessarily terminate existing authenticated sessions immediately. This highlights the importance of forced session termination during critical offboarding procedures.

Lessons Learned and Limitations

This lab provided practical insight into the nuances of Windows authentication caching and session lifecycle. A limitation of this lab is its small scale; in a large enterprise environment, replication delays across multiple Domain Controllers would introduce additional offboarding complexity that was not simulated here.

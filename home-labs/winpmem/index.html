Independent Home Lab

Scheduled Task Persistence & Volatile Memory Acquisition

Lab Status: Completed Documentation: Published

Note: This is an independent home lab investigation and not a professional SOC or client incident-response experience.

Objective and Scope

To investigate unauthorized persistence mechanisms utilizing Windows Scheduled Tasks, and to successfully execute a live physical memory acquisition using WinPmem to preserve volatile artifacts before system remediation.

Lab Environment

  • Windows 11 Pro
  • WinPmem (Memory Acquisition)
  • PowerShell & Windows Task Scheduler

What I Personally Did

  • Simulated an attacker by creating a scheduled task (SystemTelemetryUpdate) that executed a hidden PowerShell process upon user logon.
  • Enumerated scheduled tasks via CLI (schtasks /query /fo LIST /v) to identify anomalous behaviors such as SYSTEM privilege execution and hidden window parameters.
  • Initiated live response procedures prior to remediation to preserve volatile memory.
  • Acquired a physical memory image successfully using the WinPmem utility.

Observations and Supporting Evidence

The investigation demonstrated how attackers blend malicious activity with legitimate Windows administrative functions. The anomalous task executed a hidden PowerShell process (powershell.exe -NoProfile -WindowStyle Hidden -Command "Start-Sleep -Seconds 3600"). By utilizing WinPmem immediately, I successfully captured the simulated memory-resident PowerShell execution, demonstrating how volatile evidence can be preserved for deep forensic analysis (e.g., using Volatility) before the machine was rebooted.

Lessons Learned and Limitations

This exercise reinforced the critical forensic principle of order-of-volatility. Because restarting a compromised endpoint destroys volatile evidence, immediate memory acquisition is paramount. A limitation of this lab is that it focused on the acquisition phase rather than the deep memory analysis phase, which would require dedicated tools like Volatility 3 to parse the resulting memory dump.
